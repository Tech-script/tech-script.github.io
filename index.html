What is TechScript?

Imagine you want to tell a computer to do something. Normally, computers only understand confusing code with strange symbols. TechScript makes that feel like writing a sentence.

No semicolons. No brackets. No confusing symbols — just simple words that make sense. Write say to print, make to create a variable, ask to get input. That's it.

🟢 A programming language — write code that runs natively
🌐 A web builder — build full websites, no HTML/CSS needed
🦀 Powered by Native Rust — blazing fast, zero Python needed
📦 One command — tech run yourfile.txs
// why techscript

Code that makes sense.

❌ Normal JavaScript — confusing
const x = document.getElementById('name');
if (x !== null && x.value.length > 0) {
  let msg = `Hello, ${x.value}!`;
  console.log(msg);
}
✅ TechScript — reads like English
make name = ask "What is your name? "
say f"Hello, {name}!"

TechScript v1.0.3 — Evolution

🐢 v1.0.1 — The Problems
❌
The Python Flaw — Required users to install heavy Python environments just to run basic scripts.
❌
The Speed Flaw — Python's dynamic interpretation caused severe bottlenecks. A 1,000,000 loop would choke natively.
❌
The Crash Flaw — Basic errors like dividing by zero (10 / 0) would completely crash the transpiler instantly without warning.
❌
No Error Handling — attempt { } catch blocks did not exist.
🚀 v1.0.2 — The Rust Solution
✅
Native Rust VM — Entirely deleted the Python runtime. Rewrote the entire core architecture in Rust. Zero dependencies.
⚡
Blazing Fast — 1 million loop iterations in just 2.9 seconds. Native bytecode compilation.
✅
Stack Unwinding — Brand-new attempt { } catch err implementation. Division by zero safely trapped and rescued.
✅
New setup.exe — Native Windows bundle installer. Updated VS Code extension icons & syntax.
Feature🐢 v1.0.2 (Old)🚀 v1.0.3 (Latest)
StdLib Functions~15 (v1.0.2)🚀 **150+** (v1.0.3)
Cryptography❌ None✅ Native SHA-256
Loop Control⚠️ Broken✅ Fixed (stop/skip)
OS / FilesystemMinimal✅ Full Integration
JSON Support❌ Manual✅ Native Module
Safety⚠️ Some Unsafe Rust✅ 100% Zero-Unsafe Core
